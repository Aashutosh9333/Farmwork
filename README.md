# FarmWork

FarmWork is a Farm Work Management & Custom Hiring Platform connecting farmers with tractor and equipment owners.

## Vision

Manage every farm work operation from booking to billing in one platform.

## Core Users

- Farmer
- Tractor Owner
- Admin

## Core Modules

- Authentication
- Farmer Management
- Tractor Owner Management
- Equipment Management
- Booking
- Work Orders
- Land & Map Measurement
- Ledger
- Payments
- Ratings
- Weather Intelligence
- Notifications
- Admin Management

## Technology

### Frontend
